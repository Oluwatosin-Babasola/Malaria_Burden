# Malaria_Burden: Evaluation of resources allocation in Nigeria for malaria control

The analysis combined geospatial malaria data, preventive chemotherapy programme data, population denominators, and administrative boundary data to construct a state level dataset for Nigeria. All inputs were processed to the first administrative level, comprising the 36 states and the Federal Capital Territory. This spatial scale was selected to align the model with subnational planning while maintaining compatibility across malaria, neglected tropical disease, population, and boundary datasets.
Malaria burden was derived from the Malaria Atlas Project raster file for Plasmodium falciparum incidence rate in Nigeria for 2021. The raster file, 202508_Global_Pf_Incidence_Rate_NGA_2021, provided gridded estimates of malaria incidence. State boundaries were obtained from the GADM administrative boundary file gadm41_NGA_1.shp. The raster and boundary layers were first aligned to a common coordinate reference system. State level malaria incidence was then extracted using zonal statistics, with the mean raster value calculated within each state polygon. The resulting state level incidence estimates were exported as malaria_state_incidence.csv and used to compute malaria cases after merging with state population denominators.
Preventive chemotherapy data for neglected tropical diseases were obtained from the Expanded Special Project for Elimination of Neglected Tropical Diseases of WHO AFRO. Three implementation unit level files were used, namely data-NG-lf-iu-2014-2024-20260425_051157.csv for lymphatic filariasis, data-NG-SCH-iu-2014-2024-20260425_051220.csv for schistosomiasis, and data-NG-STH-iu-2014-2024-20260425_051242.csv for soil transmitted helminths. Each file contains implementation unit level information on endemicity, population requiring preventive chemotherapy, target population, treated population, coverage, epidemiological coverage, and mass drug administration status. For each disease, the most recent available year was retained. The population requiring preventive chemotherapy was aggregated from implementation units to states using the admin1 field. This produced state level values for lymphatic filariasis, schistosomiasis, and soil transmitted helminth preventive chemotherapy need.
Population denominators were extracted from the Nigeria administrative population table on CityPopulation using the 2022 state population projections. The parsed table contained 36 states and the Federal Capital Territory, where the Federal Capital Territory was listed with territory status rather than state status. Both state and territory records were therefore retained. The 2022 projection column was cleaned and renamed as population. These population denominators were used to calculate malaria cases, preventive chemotherapy need indices, and eligible populations for intervention allocation.
The three preventive chemotherapy datasets were merged by state and linked to the population dataset after standardizing state names. State names were converted to lower case, spacing and punctuation were harmonized, and the Federal Capital Territory was consistently represented as federal capital territory across malaria, preventive chemotherapy, and population datasets. After harmonization, all 37 administrative units matched across datasets. The preventive chemotherapy need for each disease was calculated as the population requiring preventive chemotherapy divided by the state population. These disease specific need values were bounded between zero and one. A combined preventive chemotherapy need index was then computed as the mean of the lymphatic filariasis, schistosomiasis, and soil transmitted helminth need indices.
Disease burden was represented using a reduced form approximation of disability adjusted life years. Malaria cases were computed by multiplying the state level malaria incidence rate by the state population and scaling by 1,000. Malaria burden was then estimated by multiplying incident cases by an average DALY per case coefficient. For neglected tropical diseases, the eligible population was defined as 35 percent of the state population, and NTD burden was estimated by multiplying the eligible population by the combined preventive chemotherapy need index and an average DALY weight. This approach provides a consistent burden measure for optimization, while avoiding unsupported decomposition into years of life lost and years lived with disability at the state level.
Commodity availability and delivery constraints were specified as model inputs rather than estimated from the disease datasets. The intervention resource limits used in the optimization were 42,000,000 units for insecticide treated nets, 12,000,000 household equivalents for indoor residual spraying, 65,000,000 units for case management, and 55,000,000 units for mass drug administration. The total budget constraint was set at 235,000,000. Unit costs were assigned to each intervention and used to calculate total expenditure under each allocation. These quantities define a reproducible resource constrained planning scenario and can be updated when verified national commodity or budget data become available.
The final merged dataset contained state name, population, malaria incidence, malaria cases, malaria burden, lymphatic filariasis need, schistosomiasis need, soil transmitted helminth need, combined preventive chemotherapy need index, eligible population for mass drug administration, and NTD burden. No state was excluded after harmonization. The final model input file was saved as nigeria_model_input_final.csv and used directly in the optimization model.
